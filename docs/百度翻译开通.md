# 百度翻译怎么开通（别走错平台）

## 最容易踩的坑：两个"百度"不是一个东西

| | ❌ 百度智能云 / 千帆 | ✅ 百度翻译开放平台 |
|---|---|---|
| 网址 | `console.bce.baidu.com` / 千帆控制台 | **`fanyi-api.baidu.com`** |
| 你能看到 | "API Keys 管理"、"大模型文本翻译"、"剩余免费额度 1000000" | "通用文本翻译"、"APP ID"、"密钥" |
| 凭据形态 | `7sK9pR2xQ5zG8dN4bV1aT6cJ0hF3mW7`（31~32 位随机串） | **APPID = 纯数字（约 17 位）**，密钥 = 32 位 |
| 认证方式 | Bearer Token / 签名换 token | `md5(appid + 查询词 + salt + 密钥)` |
| 本项目云函数用的 | ❌ 不匹配，会报 `52003 UNAUTHORIZED USER` | ✅ 就是这个 |

**症状对照**：如果你看到 `百度翻译错误 52003: UNAUTHORIZED USER`，
而你的密钥长得像一串大小写混合的随机字母数字 → **基本可以确定拿的是千帆的 Key**。

---

## 正确开通步骤

1. 打开 <https://fanyi-api.baidu.com/>
2. 点右上角 **登录**（用百度账号；没有就注册一个）
3. 登录后进入 **管理控制台** → **总览**
4. 找到 **通用文本翻译**，点 **立即使用** / **开通**
   - 个人认证即可，标准版 **100 万字符 / 终身免费**
5. 开通后进入 **管理控制台 → 开发者信息**，你会看到两行：

   ```
   APP ID：  20240101001234567        ← 纯数字，这才是 APPID
   密钥：     AbCdEfGhIjKlMnOpQrStUvWxYz123456   ← 32 位
   ```

6. 把这两个值填到**腾讯云云函数的环境变量**：

   | 变量名 | 填什么 |
   |---|---|
   | `BAIDU_APP_ID` | 上面那个**纯数字** APPID |
   | `BAIDU_APP_KEY` | 上面那个 32 位密钥 |

7. **保存并重新部署云函数**（改环境变量后必须重新部署才生效）

## 填完自己验一下（不用等云函数）

```bash
node test\tools\verify-baidu.js <你的APPID> <你的密钥>
```

它会直接调百度接口并告诉你结果：

| 输出 | 含义 |
|---|---|
| `✓✓ 密钥有效！译文: "A total of 4,441 patients..."` | 配对正确，去云函数里填环境变量即可 |
| `52003 UNAUTHORIZED USER` | APPID 不存在或与密钥不匹配 → **多半还是拿的千帆 Key** |
| `54001 Invalid Sign` | 密钥填错 |
| `54003 频率受限` | 免费版 QPS=1，等一下再试 |
| `54004 余额不足` | 免费额度用完，或没开通「通用文本翻译」 |
| `58000 IP 不在白名单` | 控制台开了 IP 白名单 → 关掉，或把云函数出口 IP 加进去 |
| `58002 服务已关闭` | 控制台里「通用文本翻译」处于关闭状态 |

## 配好之后怎么确认全部就绪

在前端点 `⚙️ 翻译服务设置` → **测试连接**，应显示：

```
服务正常。已配置引擎：tencent, baidu, deepseek
```

然后按 `docs/部署与百度翻译.md` 里的验收清单试一遍。

## 如果你确实想用千帆（百度智能云）的翻译

也可以，但云函数要**另写一个分支**（认证方式完全不同）：

- 千帆走 `Authorization: Bearer <API Key>` 或先换 access_token
- 接口是 `https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/...`（大模型）
  或千帆的机器翻译接口
- 计费按 token，不是按字符

**建议**：直接用**百度翻译开放平台**（100 万字符终身免费、接入简单、学术质量够用）。
需要千帆分支的话告诉我，我照 `docs/后端接口约定.md` 的协议加一个 `engine: 'qianfan'`。
