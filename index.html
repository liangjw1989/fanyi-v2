保版式翻译流程：解析原文件结构（段落 / 字号 / 对齐 / 缩进 / 表格 / 分栏）→ 只翻译文字、不重排结构 → 按原骨架重新生成文件。 输出 Word 可 1:1 保留版式；输出 PDF 由浏览器打印生成，版式同样保留。
🔌 翻译服务设置
填入你自己的翻译服务（云函数）地址。程序里不保存任何密钥： 腾讯云 SecretId/Key、DeepSeek API Key 都放在云函数的环境变量里。 留空则无法翻译。

🧪 排版不满意？导出诊断报告
翻译完成后点下面的按钮，会下载一份 JSON：包含 PDF 每页的 文字坐标、分栏推断、块结构。把它发给开发者，就能精确定位 「是文字层的问题」还是「版式推断的问题」。 报告里不含任何密钥。
提示：上传文件、等它解析完成（出现"解析完成"）即可导出，不必等翻译完。注意刷新页面会清空。
