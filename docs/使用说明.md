# 灵译 · 使用说明（速查）

## 一、马上用起来

1. 双击打开 `dist\index.html`（或仓库根目录的 `index.html`）。
2. 点「点击上传需翻译的文件」，选 PDF / Word(.docx) / TXT / Markdown / 图片。
3. 点 **⚙️ 术语库 · 翻译记忆 · 符号保护**：
   - **符号保护**：默认开启，别关（保护 `P<0.001`、`95%CI`、`kg/m²`、`β`、`χ²`、`[1,2]`、`图1` 等）
   - **翻译记忆**：默认开启（同样的内容只翻一次）
   - 点 **📚 载入学术常用术语** → 一键导入内置术语库（约 150 条）
4. 选语言 / 普通翻译或 AI 智能翻译 / 输出格式 → 点「▶ 翻译」。

### 输出格式怎么选

| 输出 | 适用场景 | 说明 |
|---|---|---|
| **Word** | 最常用，版式 1:1 | 完成后自动下载 `.docx` |
| **PDF** | 想直接得到 PDF | 会打开排版页 → 打印对话框里选「另存为 PDF」 |
| **中英对照** | 核校、汇报 | 左右双语逐段对照 |
| **HTML** | 网页发布 | 保留版式的网页 |
| **纯文本** | 只要文字 | 保留段落与表格制表符 |

## 二、术语库怎么用

在术语库文本框里，**每行一条**，格式 `源词 = 目标译法`：

```
精子DNA碎片化指数 = sperm DNA fragmentation index
不育男性 = infertile men
参考文献 = References
# 井号开头是注释，不生效
```

规则与技巧：

- **长词优先**：写 `精子DNA碎片化指数` 就不用再单独写 `精子DNA`；
- **术语内部不再拆符号**：整条术语作为一个整体替换，里面的 `DNA`、`4441例` 不会被单独抠出来；
- 术语是**强制替换**的，翻完会自动填回你指定的译法 —— 这是保证"前后译名一致"的关键；
- 支持从文件导入（`.txt/.csv/.tsv`）与导出，方便多台机器/多人共用同一套术语表。

## 三、翻译记忆怎么用

- 翻译过的段落会记下来（存在浏览器本地），**同样内容第二次直接复用，零接口调用**；
- 改稿后重译：只有改动过的段落会真正发送翻译，省时间也省钱；
- 「导出 / 导入」可以备份成 JSON，换电脑或换浏览器都不丢；
- 容量上限 20000 条，超出后自动淘汰"用得最少 + 最久没用"的条目。

## 四、常见问题

**Q：提示"翻译接口返回错误"？**
A：检查网络能否访问云函数地址；若接口额度用尽，请更换密钥或稍后再试。

**Q：扫描件 PDF 没有译文？**
A：扫描件没有文字层，程序拿不到文字。请把 PDF 转成图片后用"图片"模式（走 OCR），
或先用 OCR 软件转成可选中文字的 PDF。

**Q：上传 `.doc` 报错？**
A：浏览器无法解析老 `.doc`，请先用 Word/WPS 另存为 `.docx`。

**Q：PDF 输出的版式和原文件"几乎一样"但不完全一致？**
A：PDF 本身只是"打印结果"，没有段落语义，程序是按坐标还原的；
论文里的多行公式、竖排文字会有偏差。追求 1:1 时建议**优先要 Word 版**。

**Q：符号保护会不会误伤？**
A：它只保护"确定的模式"（数字+单位、统计量、上下标、希腊字母、文献编号、图表编号）。
如果发现某个词被误保护，把它写进术语库并按需要的译法指定即可。

**Q：翻译记忆会不会把旧译文用错？**
A：命中要求"归一化后完全一致"（忽略空格、换行、全半角差异）。改了字就不会命中，
会重新翻译并更新记忆。

## 五、开发者速查

```bash
node build.js            # 打包：app + src → dist/index.html（含版权水印与构建指纹）
node run-tests.js        # 全部测试（101 项）
node make-repo.ps1       # 生成可上传 GitHub 的干净目录 repo\
```

- 改界面 → `app/index.html`
- 改解析/版式 → `src/layout.js`、`src/pdf-extract.js`、`src/docx-extract.js`
- 改译文质量 → `src/glossary.js`（符号与术语）、`src/translate.js`（流水线与提示词）
- 改输出效果 → `src/render-docx.js`、`src/render-html.js`

改完先跑 `node build.js`，再跑 `node run-tests.js` 确认没退化。
