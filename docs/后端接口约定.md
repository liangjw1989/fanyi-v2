# 后端接口约定（云函数）

灵译前端**不含任何密钥**。它只做一件事：把文本 POST 到一个你自己部署的云函数。
密钥（腾讯云 SecretId/SecretKey、DeepSeek API Key）全部放在**云函数的环境变量**里。

> 这正是你现在的架构，**不需要改动**：后端继续用腾讯云函数即可，
> 上传 GitHub 的只有前端程序。

---

## 1. 部署者需要在腾讯云控制台配置的环境变量

| 变量名 | 用途 | 说明 |
|---|---|---|
| `TMT_SECRET_ID` | 腾讯云机器翻译 SecretId | 控制台 → 访问管理 → API 密钥管理 |
| `TMT_SECRET_KEY` | 腾讯云机器翻译 SecretKey | 同上 |
| `DEEPSEEK_API_KEY` | DeepSeek API Key | DeepSeek 开放平台 → API Keys |

**这几项永远不要写进前端代码、`config.js` 或 GitHub。**
它们只存在于：腾讯云控制台 → 你的函数 → 配置 → 环境变量。

安全性说明：即使函数 URL 被别人知道，对方也只能"调用"，拿不到你的密钥；
真正的风险是被白用额度。若担心，可在云函数里加：

- 来源校验（只允许你的域名 `Origin`）
- 简单的每日调用次数限制
- 一个前端约定的小令牌（注意：前端令牌同样可被看到，只能挡顺手党）

---

## 2. 接口协议

**请求**（POST，`Content-Type: application/json`）：

```json
{
  "text":   "待翻译文本（可能含 ⟦0⟧ ⟦P1⟧ ⟦T2⟧ 这类占位符）",
  "target": "zh | en | ja | ko | fr | de | ...",
  "engine": "tencent | deepseek | reformat",
  "system": "（仅 deepseek 时携带）系统提示词"
}
```

**响应**：

```json
{ "code": 0, "result": "翻译结果文本" }
```

失败时 `code` 非 0，`result` 放错误信息。

### engine 的语义

| engine | 行为 | 对应界面选项 |
|---|---|---|
| `tencent` | 腾讯云机器翻译，**不重排、只翻译**，最稳 | 普通翻译 |
| `deepseek` | 大模型翻译 + 润色（提示词由前端传入 `system`） | AI 智能翻译 |
| `reformat` | 仅排版（本项目已不再使用，可保留兼容） | — |

### 三条硬性要求（决定排版与符号能否保住）

1. **单个片段原样返回**：请求里的 `⟦数字⟧` 标记必须数量、编号、顺序一致地出现在 `result` 里。
2. **占位符原样保留**：`⟦P0⟧`（数字/单位/上下标/文献编号）与 `⟦T1⟧`（术语）不能翻译、不能改写。
   前端翻完会把它们原地填回，所以引擎只要"别动"就够了。
3. **不要自作主张分段或合并**：一行请求对应一段文本，别做 Markdown 重排。

> 用腾讯云 TMT 时天然满足这三点（它就是逐字翻译，不改标记）。
> 用 DeepSeek 时满足靠的是前端传入的 `system` 提示词（已内置这些约束）。

## 3. 云函数参考实现（腾讯云 SCF，Node.js）

最小可用版本（省略签名与错误处理的细节，完整实现见你的备份 `云备份儿\云函数.txt`）：

```js
'use strict';
const axios = require('axios');
const crypto = require('crypto');

const HOST = 'tmt.tencentcloudapi.com';
const SERVICE = 'tmt';
const ACTION = 'TextTranslate';
const VERSION = '2018-03-21';
const REGION = 'ap-guangzhou';

function getSignature(secretId, secretKey, payload, timestamp) {
  const headers = {
    'Content-Type': 'application/json',
    Host: HOST,
    'X-TC-Action': ACTION,
    'X-TC-Version': VERSION,
    'X-TC-Timestamp': timestamp,
    'X-TC-Region': REGION
  };
  const canonicalHeaders = 'content-type:application/json\nhost:' + HOST + '\n';
  const signedHeaders = 'content-type;host';
  const hashedPayload = crypto.createHash('sha256').update(JSON.stringify(payload)).digest('hex');
  const canonicalRequest = ['POST', '/', '', canonicalHeaders, signedHeaders, hashedPayload].join('\n');
  const dateStr = new Date(timestamp * 1000).toISOString().slice(0, 10);
  const scope = dateStr + '/' + SERVICE + '/tc3_request';
  const stringToSign = ['TC3-HMAC-SHA256', timestamp, scope,
    crypto.createHash('sha256').update(canonicalRequest).digest('hex')].join('\n');
  const kDate = crypto.createHmac('sha256', 'TC3' + secretKey).update(dateStr).digest();
  const kService = crypto.createHmac('sha256', kDate).update(SERVICE).digest();
  const kSigning = crypto.createHmac('sha256', kService).update('tc3_request').digest();
  const signature = crypto.createHmac('sha256', kSigning).update(stringToSign).digest('hex');
  headers.Authorization = 'TC3-HMAC-SHA256 Credential=' + secretId + '/' + scope +
    ', SignedHeaders=' + signedHeaders + ', Signature=' + signature;
  return headers;
}

async function callTencent(text, target) {
  const secretId = process.env.TMT_SECRET_ID;      // ← 环境变量，不写死在代码里
  const secretKey = process.env.TMT_SECRET_KEY;
  if (!secretId || !secretKey) throw new Error('腾讯云密钥未配置');
  const timestamp = Math.floor(Date.now() / 1000);
  const payload = { SourceText: text.substring(0, 6000), Source: 'auto', Target: target, ProjectId: 0 };
  const res = await axios.post('https://' + HOST, payload, { headers: getSignature(secretId, secretKey, payload, timestamp) });
  if (res.data?.Response?.Error) throw new Error(res.data.Response.Error.Message);
  return res.data?.Response?.TargetText || '';
}

async function callDeepSeek(text, target, system) {
  const key = process.env.DEEPSEEK_API_KEY;        // ← 环境变量，不写死在代码里
  if (!key) throw new Error('DeepSeek API Key 未配置');
  const res = await fetch('https://api.deepseek.com/v1/chat/completions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + key },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [
        { role: 'system', content: system || ('Translate into ' + target + '. Keep every ⟦n⟧ and ⟦P/T n⟧ marker exactly as-is.') },
        { role: 'user', content: text }
      ],
      temperature: 0.1
    })
  });
  const data = await res.json();
  return data?.choices?.[0]?.message?.content || '';
}

exports.main_handler = async (event) => {
  let body = event.body;
  if (typeof body === 'string') { try { body = JSON.parse(body); } catch { return { statusCode: 400, body: JSON.stringify({ code: -1, result: '请求体不是合法 JSON' }) }; } }
  const text = body.text || '';
  const target = body.target || 'zh';
  const engine = body.engine || 'tencent';
  if (!text) return { statusCode: 400, body: JSON.stringify({ code: -1, result: '缺少 text' }) };
  try {
    const result = engine === 'deepseek'
      ? await callDeepSeek(text, target, body.system)
      : await callTencent(text, target);
    return { statusCode: 200, body: JSON.stringify({ code: 0, result }) };
  } catch (err) {
    return { statusCode: 500, body: JSON.stringify({ code: -1, result: err.message }) };
  }
};
```

部署要点：

1. 运行环境选 **Node.js 18+**（要用到全局 `fetch`；更低版本请用 axios 调 DeepSeek）。
2. 依赖里加 `axios`（腾讯云翻译签名需要）。
3. **环境变量务必配齐** `TMT_SECRET_ID`、`TMT_SECRET_KEY`、`DEEPSEEK_API_KEY`。
4. 触发器选 **API 网关**，记下分配到的 URL，填到前端「翻译服务设置」里。

## 4. 前端怎么配置这个地址

三种方式，任选：

| 方式 | 位置 | 适用 |
|---|---|---|
| 界面里填 | 程序页 →「⚙️ 翻译服务设置」→ 填 URL → 保存（存在本机 localStorage） | 所有用户，最简单 |
| `config.js` | 仓库根目录的 `config.js`，改 `API_URL` | 自己的私有部署 |
| 都不填 | 程序会提示"还没有配置翻译服务地址" | 公开仓库的默认状态 |

**公开仓库建议**：`config.js` 里 `API_URL` 留空，让使用者填自己的地址；
这样你的额度不会被陌生人消耗。

`config.js` 里**只有地址**，永远不要放密钥。可以安全地提交到 GitHub。
