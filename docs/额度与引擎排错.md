# 翻译不出来 / 生成的文件还是全英文？先看引擎额度

## 一句话结论

灵译本身不做翻译，它调用你自己的云函数；云函数再去调腾讯云、百度或 DeepSeek。
**任何一个引擎的"当月免费额度用完"或"密钥失效"，都会让翻译整体失效。**
2026 年 11 月就发生过：腾讯云当月 500 万字符免费额度用完，一份 25 页论文被静默
输出成 10 万英文字符、0 个中文字符的 Word，界面上没有任何报错。

## v2.8.2 之后的行为（重要）

- **自动切换**：你选腾讯云，但它额度用完 → 程序会自动改用 DeepSeek 或百度继续翻，
  并在文件行下面提示"已自动改用百度翻译"。
- **绝不假装成功**：所有引擎都不可用时，会明确报错
  `翻译失败：翻译服务不可用：……请更换引擎（推荐 DeepSeek 或百度翻译），或检查云函数额度。`
  不会再产出"看着完成了、其实全是原文"的文件。

## 各引擎的免费额度（2026-11 实测）

| 引擎 | 免费额度 | 说明 |
|---|---|---|
| 腾讯云机器翻译 | 每月 500 万字符 | 本月已用完，下月 1 号恢复 |
| 百度翻译 | 每月 5 万字符（标准版） | 语种多、速度快 |
| DeepSeek | 无免费额度，按 token 计费 | 学术文本质量最好 |

## 怎么判断是额度问题

1. 页面上点「测试连接」：返回 `服务正常。已配置引擎：tencent, baidu, deepseek` 只说明**密钥在**，
   不代表**额度还有**。
2. 点「⚙ 术语库…」→「导出诊断报告（JSON）」，查看 `translate.engine` 与失败信息。
3. 直接用命令行验证某个引擎（把 URL 换成你的云函数地址）：

```powershell
$body = '{"text":"chronic stress","target":"zh","engine":"tencent"}'
Invoke-RestMethod -Uri "https://你的云函数地址" -Method Post -ContentType "application/json" -Body $body
```

- 返回 `{"code":0,...,"engine":"baidu"}` → 腾讯云挂了，云函数已自动兜底到百度
- 返回 `HTTP 500 {"code":-1,"result":"所有引擎均失败 → ..."}` → 三个引擎都不可用
- 返回 `{"code":0,"result":"慢性压力"}` → 该引擎正常

## 建议

- 平时用 **百度翻译**（免费额度大、速度快）；要质量就用 **DeepSeek**。
- 腾讯云额度用完不必删密钥，等下月恢复或改用别的引擎即可。
- 云函数代码在 `deploy/云函数.js`，改了要**重新部署**才生效（网页端不需要重新部署）。
