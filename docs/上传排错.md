## 0. 你当前网络的实测结论（2026-10-06）

| 检查项 | 结果 | 含义 |
|---|---|---|
| `github.com` HTTPS | ❌ 超时 | 网页打不开；`git push` 默认走这条 |
| `github releases CDN` HTTPS | ❌ 超时 | 所以 winget 装 Git 失败（`0x80072efd`） |
| `raw.githubusercontent.com` | ❌ 连接被关闭 | 同上 |

| `api.github.com` | ✅ 200 | GitHub API 通 |
| `gitee.com` | ✅ 200 | 国内通道完全可用 |

| `git-scm.com` | ✅ 200 | 官网可开 |

**一句话结论：HTTPS 被拦（SNI 层），SSH 通。所以推 GitHub 走 SSH 即可，不必翻墙。**

## 1. 三步走（推荐顺序）

### 第 1 步：装 Git（HTTPS 被拦，不能用 winget）

双击 `install-git.bat`；它会先试 **Microsoft Store 源**（走微软 CDN），失败则用镜像手动下载。

镜像（都已验证可达，浏览器直接打开）：

| 镜像 | 地址 |
|---|---|
| 华为云 | `https://mirrors.huaweicloud.com/git-for-windows/` |
| 阿里 npmmirror | `https://registry.npmmirror.com/-/binary/git-for-windows/` |
| 官网 | `https://git-scm.com/download/win` |

进**版本号最高**的 `v2.x.x` 目录 → 下载 `Git-2.x.x-64-bit.exe` → 双击，**一路默认** →
关闭所有命令行窗口 → 新开窗口执行 `git --version` 确认。

> 注意：`mirrors.tuna.tsinghua.edu.cn` 这次返回 403，别用它。

### 第 2 步：配置 SSH（不用翻墙）

双击 **`setup-github-ssh.bat`**，它会：生成密钥 → 测试连接 → 把公钥复制到剪贴板并打开记事本。

然后在**任意能打开 github.com 的网络**（手机热点、VPN、或朋友的电脑）访问：

```
https://github.com/settings/ssh/new
```

Title 随便填（如 `lingyi`），Key 粘贴刚才的公钥 → `Add SSH key`。

### 第 3 步：用 SSH 推送

在 `repo` 目录（本文件所在目录）执行：

```bash
git init
git branch -M main
git add -A
git commit -m "feat: 保版式文档翻译 v2.1"
git remote add origin git@github.com:你的用户名/仓库名.git
git push -u origin main
```

之后 `upload-to-github.bat` 也能用（它内部就是 git 命令，SSH 地址同样适用）。

## 2. 如果第 2 步加不了公钥（github.com 任何方式都打不开）

那么 GitHub 这条路暂时走不通，用 **Gitee（码云）**，已实测可达：

1. 双击 **`upload-to-gitee.bat`**（先改开头两行为你的名字/邮箱）。
2. 提前去 `https://gitee.com/projects/new` 建一个**空仓库**（不要勾任何初始化选项）。
3. 脚本会提示粘贴仓库地址，之后自动 init / commit / push。
4. 想在网页上给别人用：仓库 → `服务` → `Gitee Pages` → 部署。

以后 GitHub 能访问了，再加一份镜像：

```bash
git remote add github git@github.com:你的用户名/仓库名.git
git push github main
```

## 3. 排查与命令速查

### 重新诊断

| 脚本 | 作用 |
|---|---|
| `check-network.bat` | 测 9 个域名，判断能否上传 GitHub |
| `check-github-channel.bat` | 深测各条通道（HTTPS 443 / SSH 22 / SSH 443） |

### 强制 SSH 走 443 端口（若哪天 22 被封）

在 `C:\Users\<你>\.ssh\config` 写入：

```
Host github.com
  HostName ssh.github.com
  Port 443
  User git
  IdentityFile ~/.ssh/id_ed25519_github
```

然后 `ssh -T git@github.com` 验证。

### 用代理（若有）

```bash
git config --global http.proxy  http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
# 取消：
git config --global --unset http.proxy
git config --global --unset https.proxy
```

### 常见报错

| 报错 | 含义 | 处理 |
|---|---|---|
| `Permission denied (publickey)` | SSH 通了，但没加公钥/加的账号不对 | 按第 2 步把公钥加到 GitHub |
| `Repository not found` | 地址错或仓库不存在 | 网页确认，`git remote set-url origin <新地址>` |
| `Failed to connect` / `timed out` | 该通道被拦 | 换 SSH / 换 Gitee / 上代理 |
| `updates were rejected` | 远程有本地没有的提交 | `git pull --rebase origin main` 后重推 |
| `src refspec main does not match any` | 还没提交 | `git add -A` → `git commit -m "init"` |
| `LF will be replaced by CRLF` | 换行符提示 | 可忽略（仓库已带 `.gitattributes`） |
